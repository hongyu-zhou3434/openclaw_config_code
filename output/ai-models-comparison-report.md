## 三、模型架构深度对比

### 3.1 架构概览

| 模型 | 架构类型 | 核心技术 | 创新点 |
|------|----------|----------|--------|
| **Kimi 2.5** | Dense Transformer | 长上下文优化 | 无损长文本压缩 |
| **GLM 5.0** | GLM (General Language Model) | 自研架构 | 双向+单向统一 |
| **MiniMax** | Dense Transformer | 多模态融合 | 端到端生成 |
| **DeepSeek V3** | **MoE (Mixture of Experts)** | 专家路由 | 共享专家+路由专家 |

### 3.2 DeepSeek MoE 架构详解

```
┌─────────────────────────────────────────────────────────┐
│                  DeepSeek V3 架构                        │
├─────────────────────────────────────────────────────────┤
│  Total Params: 671B                                     │
│  Activated Params: 37B per token                        │
│  Expert Count: 256 (256 routed + 1 shared)              │
│  Top-k: 6 experts per token                             │
├─────────────────────────────────────────────────────────┤
│  ┌─────────────┐    ┌─────────────────────────────┐    │
│  │ Input Token │───▶│ Router Network              │    │
│  └─────────────┘    └─────────────────────────────┘    │
│                              │                          │
│                              ▼                          │
│  ┌──────────────────────────────────────────────────┐  │
│  │ Select Top-6 Experts from 256 routed experts     │  │
│  │ + Always-active shared expert                    │  │
│  └──────────────────────────────────────────────────┘  │
│                              │                          │
│                              ▼                          │
│  ┌──────────────────────────────────────────────────┐  │
│  │ Expert Computation (37B activated)               │  │
│  │ - Shared expert: ~4B                             │  │
│  │ - 6 Routed experts: ~33B                         │  │
│  └──────────────────────────────────────────────────┘  │
│                              │                          │
│                              ▼                          │
│  ┌─────────────┐                                      │
│  │ Output      │                                      │
│  └─────────────┘                                      │
└─────────────────────────────────────────────────────────┘
```

**DeepSeek MoE 创新点**:
1. **共享专家 (Shared Expert)**: 所有 token 共享的专家，学习通用知识
2. **路由专家 (Routed Expert)**: 256个专家，每个 token 选择 Top-6
3. **负载均衡**: 辅助损失函数确保专家负载均衡
4. **设备限制路由**: 限制专家分布在特定设备，减少通信开销
